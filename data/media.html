Diagnostics, test status and limitations

Safari background execution is not guaranteed; when the screen locks, browser-based stalk forwarding can stop. Spotify can return 403, 404, 429 or 204. A SoftAP-only bridge does not supply Internet. This page never injects CAN data or emulates a CD changer; EMF-C display experiments require separately verified CAN captures.
